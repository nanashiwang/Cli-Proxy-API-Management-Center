# 账号并发显示

认证文件卡片新增“本机并发”，随现有列表刷新更新。点击或使用键盘展开说明和观测时间。

- `3 / 不限`：本进程正在执行 3 个请求，CPA 未设置本地账号并发上限，不代表上游没有限额。
- `0 / 上限未知`：已采集本地执行数，但无法从本机推算 Home 的共享上限。
- `— / 上限未知`：后端尚未提供数据，不显示成空闲或满载。
- 若后端提供明确的有限上限，达到上限才显示“满载”。本次配套后端不新增调度限流规则。

并发数与额度、冷却、停用状态及独享租约分别显示。排队、空闲 WebSocket 和租约归属不计入并发；取消后仍存活的生产者须退出后才释放计数。

参考 codex-proxy-rs 的 `ea4e3059db5d2e744518fec5dd8df10b5905b867` 和 `2a65b53b44b3e15551746ed0424e96aef5f35b34`，适配为 CPA 的 Go / React 契约。旧后端可继续使用管理页，新增信息显示为未知。

验证：561 项测试、TypeScript、生产构建通过；真实项目页面以模拟管理 API 验证桌面、390px 暗色、刷新、键盘展开、旧后端缺失字段和请求失败。模拟数据不代表线上账号状态。
